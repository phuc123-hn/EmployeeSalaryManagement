======================================================================
✨ CÁC TÍNH NĂNG CHỦ YẾU
======================================================================

1. ĐĂNG NHẬP & PHÂN QUYỀN
   - Login với 2 role: Admin + User
   - Phân biệt quyền hạn

2. TÍNH LƯƠNG CHI TIẾT
   - Lương Gross (Trước trừ)
   - Bảo Hiểm BHXH (5%) + BHYT (1.5%)
   - Thuế PIT (Thuế thu nhập cá nhân)
   - Lương Net (Thực lĩnh)

3. QUẢN LÝ NHÂN VIÊN (Admin)
   - Thêm/xóa nhân viên
   - Tìm kiếm (không block UI)
   - Xuất báo cáo CSV

4. CHẤM CÔNG (All users)
   - Check-in thực tế
   - Check-out thực tế
   - Xem lịch sử chấm công

5. XEM LƯƠNG CỦA TÔI (User)
   - Chi tiết lương cá nhân
   - Breakdown thuế & bảo hiểm

======================================================================
📊 CÔNG THỨC TÍNH LƯƠNG
======================================================================

Lương Net = Lương Gross - Bảo Hiểm - Thuế PIT

Ví dụ:
  Lương Gross: 5,000,000 VND
  Bảo Hiểm (6.5%): 325,000 VND
  Thuế PIT: 0 VND (< mức giảm trừ)
  ────────────────────────────
  Lương Net: 4,675,000 VND

======================================================================
💾 CẤP NHẬT CODE
======================================================================

Khi sửa code trong src/:

  1. Sửa file .java trong src/
  2. Chạy: compile.bat
     hoặc: javac -encoding UTF-8 -d bin src/*.java
  3. Chạy: run.bat
     hoặc: java -cp bin QLLuongVien

======================================================================
❓ CÓ LỖI?
======================================================================

Q1: "javac: command not found"
A: Cần cài Java JDK (không phải JRE)
   Download tại: https://www.oracle.com/java/technologies/downloads/

Q2: "Main class QLLuongVien not found"
A: Đảm bảo:
   - Chạy từ thư mục 01-test/
   - File QLLuongVien.class có trong bin/
   - Dùng: java -cp bin QLLuongVien

Q3: Ký tự Tiếng Việt hiển thị lạ
A: Đảm bảo compile với: -encoding UTF-8
   (Đã cấu hình sẵn trong compile.bat)
